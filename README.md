# 🏴‍☠️ Ye Olde Stack Trace

> **Turning Developer Panic into Comedic Lore & Team Laughter** ⚔️📜  

---

## 🌟 What is this?

Ever faced a scary `NullPointerException` or `500 Internal Server Error` at 4:45 PM on a Friday?

**Ye Olde Stack Trace** is a lightweight web app that translates raw runtime error logs into hilarious lore:
- 🏴‍☠️ **17th-Century High-Seas Pirate Logs:** Memory leaks become leaks in the starboard hull; null pointers become ghost captains plundering registers.
- 🎻 **14th-Century Medieval Court Bard Ballads:** Out-of-memory errors become tragic famines in the king's grand vault, rendered in rhyming verse.

---

## 🛠️ Stack & Tools

- **Frontend:** HTML5, CSS3 (Parchment UI styling), Vanilla JS (`index.html`)
- **Backend:** AWS Lambda using Python 3.12 (`lambda_function.py`)
- **AI Engine:** Amazon Bedrock (`amazon.nova-micro-v1:0`)
- **Hosting:** AWS Amplify Hosting
